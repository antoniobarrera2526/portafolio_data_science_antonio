# Portafolio de Ciro Antonio Medina Barrera

Sitio web estático creado con HTML, CSS y JavaScript, listo para publicar en GitHub Pages.

## Archivos

- `index.html`: contenido y estructura del portafolio.
- `styles.css`: diseño adaptable a móviles y escritorio.
- `script.js`: menú móvil y pequeños comportamientos.
- `assets/CV-Antonio-Medina-Barrera.pdf`: hoja de vida enlazada desde el botón de descarga.

## Antes de publicar

1. Reemplaza los enlaces `href="#"` de los proyectos por las URL reales de GitHub y Streamlit.
2. Reemplaza `https://www.linkedin.com/` por la URL exacta de tu perfil de LinkedIn.
3. Revisa si deseas mantener visible tu número telefónico en una página pública.
4. Si actualizas tu CV, reemplaza el PDF de `assets/` conservando el mismo nombre o actualiza el enlace en `index.html`.

## Publicar en GitHub Pages

1. Crea un repositorio público llamado exactamente `TU-USUARIO.github.io`.
2. Descomprime este paquete y sube al repositorio el contenido de la carpeta (no la carpeta contenedora).
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que termine el despliegue. Tu sitio quedará disponible en `https://TU-USUARIO.github.io`.

## Personalización

El contenido está en español y utiliza los datos de la hoja de vida suministrada. Puedes editar textos directamente en `index.html` y colores en la sección `:root` de `styles.css`.
